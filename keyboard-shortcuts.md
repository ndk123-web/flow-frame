# Workspace Keyboard Shortcuts

Use these quick keyboard commands to manage nodes and playback inside the visual workspace:

| Keyboard Key | Action description |
| :--- | :--- |
| **Delete / Backspace** | Delete the currently selected node or connection edge. |
| **Spacebar** | Toggle simulation playback run (Play / Pause). |
| **Arrow Right (→)** | Seek forward to the next simulation animation frame. |
| **Arrow Left (←)** | Seek backward to the previous simulation animation frame. |
| **Escape** | Close active modals, menus, or deselect active nodes. |
