# FlowFrame Examples Library

This directory contains high-level, real-world architecture templates that you can import directly into the FlowFrame Sandbox workspace.

## How to Import a Template

1. Navigate to the FlowFrame visual workspace.
2. In the left sidebar footer panel, click **Import**.
3. Select any `.json` file from these subdirectories.
4. The topology will load instantly. You can inspect node parameters, re-arrange components, or run simulations to test packet flows.

## Template Catalog Index

- **architectures/**: Real-world patterns (Monolith, Microservice, Scalable Web Backend, Event-Driven, URL Shortener).
- **caching/**: Cache topologies (Cache-Aside, Write-Through, Write-Back buffers).
- **database/**: Data routing layers (Connection Pooling, Master-Replica, Sharding partitions).
- **messaging/**: Async patterns (Message Queue pipelines, Pub/Sub brokers, Worker groups).
- **analytics/**: Logging flows (Async analytics queues).
