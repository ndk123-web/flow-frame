# Interactive Learning Scenarios

FlowFrame acts as a training platform for distributed system designs by hosting structured scenarios.

## Scenario Challenges

Interactive scenarios guide users through common system design challenges. Each scenario includes:
- **Description**: Educational overview of the system design pattern (e.g. Caching, Load Balancing).
- **Objectives**: Explicit performance guidelines, such as handling traffic spikes, managing database load, or avoiding cache stamps.
- **Validation**: System validation logic that checks if the user's connection layouts and configs solve the scenario target.

## Concept Glossary

The Glossary serves as a directory of distributed terms.
- **Pathing**: `/learn/glossary`
- **Details**: Provides clean definitions and structural descriptions of patterns like Round Robin, CDN Edge Servers, Postgres Pools, Write-Through caching, and Event queues.
