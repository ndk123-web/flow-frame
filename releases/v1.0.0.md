# Release Notes - v1.0.0

FlowFrame aims to make distributed systems easier to understand through interactive simulations.

## Features Added
- **Load Balancing**: Distribute traffic across backends.
- **Cache-Aside Pattern**: Look up data from cache first, then fall back to database.
- **API Gateway Routing**: Route requests based on URL path prefixes.
- **Valet Key Pattern**: Issue token keys to clients for direct content upload routing.

## Future Work Interest
- Exploring failure modes (Redis latency, cache expiration, and service failures).
