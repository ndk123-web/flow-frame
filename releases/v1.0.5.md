# Release Notes - v1.0.5

Implemented template export tools, canvas screenshot generators, and social hooks.

## Features Added
- **Import/Export**: Serialize topologies into reusable JSON files and restore them in the sandbox.
- **PNG Screenshots**: Download diagram viewports as PNG files with clean light/dark themed backgrounds.
- **Social Sharing hooks**: Integrated LinkedIn feed post copy captions and X (Twitter) tweet text intents.
